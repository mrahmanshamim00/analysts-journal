# Analyst's Journal

Personal political analysis website using the Editorial Authority design system.

## Deployment

This site is deployed via GitHub Pages. To update:
1. Edit the HTML files
2. Commit and push changes
3. GitHub Pages will auto-deploy from the `main` branch

## Customization

- `index.html` - Homepage
- `about.html` - About page
- `essay.html` - Essay template

Replace placeholder content with your own name, bio, and essays.
